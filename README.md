# AAC — algorithm experiments

C++ class exercises and measurement notes on algorithm performance. This repository documents learning and experimentation; it is not a production library.

## Repository map

| Folder | Focus |
| --- | --- |
| [Class 2](Class%202) | Random-number generation and measurements |
| [Class 3](Class%203) | Measuring vector `push_back` performance |
| [Class 4](Class%204) | Merge sort, selection sort and comparisons |
| [Class 5](Class%205) | Heap sort and comparison notes |
| [Class 6](Class%206) | Quicksort and worst-/average-case comparisons |
| [Class 7](Class%207) | Counting sort and comparisons across sorting algorithms |

The folders contain source files and, where available, Markdown reports, plots or measurement outputs. Start with the report in the exercise you want to inspect, then read its source.

## Interpreting the results

These are local exercise measurements. Timings depend on the machine, compiler, build settings and input data; they should not be read as universal performance guarantees. There is no unified build or test entry point documented for this repository.
